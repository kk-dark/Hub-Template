# Hub-Template

本仓库用于维护项目协作规范、版本控制规则和 C++/Qt 开发文档，为贡献者和自动化代理提供统一的工作约定。

## 文档入口

- [贡献指南](CONTRIBUTING.md)
  Issue、Commit、PR 和代码规范的入口说明。
- [版本控制规范](VERSIONING.md)
  版本号、版本发布和变更说明规则。
- [目录结构](docs/module-structure.md)
  仓库目录和文件职责说明。
